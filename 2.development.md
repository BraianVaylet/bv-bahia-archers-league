# Desarrollo

## Stack

- Para el FrontEnd se usara React y TypeScript
- Para el BackEnd se usara Node
- Como base de datos se usara MongoDb
- Se alojara en raillway

## Landing page
Debe tener las siguientes secciones:
1. Seccion Introduccion: Con Titulo, Descripcion, Accesos a las wab apps WAFA y WAFL.
2. Seccion Ranking: Ranking de la liga separado por categoria. Hay dos tipos de ranking: 
- ranking por mejor puntaje: Se ganan puntos por la posicion de cada torneo, 1er lugar gana 5 puntos, 2do lugar 4 pts, 3re lugar 3pts, 4to lugar 2 pts, 5to lugar 1 punto, el resto no recibe puntaje (esto es por categoria)
- ranking por puntos: Se elije el mejor puntaje de los torneos tirados.
(es necesario tener al menos 2 torneos para entrar en los rankings)
3. Seccion Listado de torneos: Se muestra la lista de torneos realizados y en proceso, se puede ingresar y ver las estadisticas de cada uno (cantidad de blancos, modalidad de cada uno, cantidad de flechas por blanco, puntajes de cada arquero por blanco, cantidad de X, de 10 y de M, podios por categorias, mejores puntaje por categoria). Si el torneo esta en proceso sirve para ver la distribucion de patrullas.
4. Seccion arquero: Al seleccionar a un arquero del ranking se accede a una nueva pagina donde se pueden ver estadisticas del arquero (cantidad de torneos tirados, mejor puntaje, peor puntaje, cantidad de x, cantidad de 10, cantidad de M)

## WAFA (Web App for Admin)
Debe tener las siguientes secciones/paginas:
1. LOGIN: Debe tener un login para acceder. El usuario sera admin y el password CBA2026.
2. HOME: En la pagina principal se veran listados todos los torneos creados (los completados y el que esta en proceso). Desde la Home se debe poder crear nuevos torneos.
3. CREAR_TORNEO: En la pagina de creacion de torneos se debe poder elegir los siguientes puntos:
- Nombre del torneo
- Fecha del torneo
- Descripcion del torneo
- Cantidad de blancos del torneo
- Para cada blanco se debe elegir la modalidad (sala, aire libre, juego de campo, 3D) (son torneos multitarget)
- La cantidad de flechas a tirar en cada blanco (por defecto usara la del reglamento que corresponda, pero puede setearse por el admin en caso de querer tirar mas o menos).
- Los participantes del torneo (se deben poder elegir del listado de arqueros cargados en la plataforma o agregar nuevos).
- Antes de crear el torneo se debe poder editar los datos cargados, cambiar el orden de los blancos, agregar mas o eliminar alguno.
4. ARQUEROS: Listado de arqueros registrados, se pueden editar, borrar, archivar y crear nuevos. (solo se pueden borrar arqueros que no esten asociados a ningun torneo, una vez entran en el ranking no pueden eliminarse, si se pueden archivar para no volverlos a incluir en torneos futuros).
- CARGA_ARQUEROS: Para cargar un arquero en la plataforma se necesita cargar la siguiente informacion: Nombre, Apellido, Categoria (Lonbow, Tradicional, Razo, Recurvo, Cazador, Compuesto, Escuela).
5. RANKING: Pagina donde se puede ver el listado del ranking de arqueros por categoria, el mismo que en la landingpage.
6. TORNEO: En esta pagina se puede acceder a la informacion de un torneo (completado o en curso).
- Si es un torneo completado solo se pueden ver y no editar. Se puede ver la configuracion del torneo (cantidad, de blancos, modalidades, cantidad de flechas, etc. Tambien se puede ver los podios por categoria y la cantidad de puntos que cada arquero sumo.)
- Si es un torneo en curso, solo se puede editar los blancos que no fueron tirados por ninguna patrulla, una vez alguna patrulla ya registro puntos en un blanco este no puede ser editado ni eliminado. Se pueden ver estadisticas del torneo, cuantos blancos completo cada patrulla y los puntages de cada arquero. Una vez todos los equipos completaron el torneo desde la WAFL (web app for leaders). El torneo pasa de estado a completado y se habilita la opcion de publicar, una vez el admin publica el torneo los puntajes se ven aplicados a los podios y a los ranking (los arqueros lo pueden visualizar desde la landing page).
- Cada torneo tiene los siguientes estados: sin_iniciar, en_proceso, completado, publicado.
- Para los torneos en curso se puede acceder a una seccion PATRULLAS donde se listan todas las patrullas con su distribucion, blanco de inicio y usuario-contraseña para ingresar a la WAFL. 

## WAFL (web app for leader)
Debe tener las siguientes secciones/paginas:
1. LOGIN: Debe tener un login para acceder. El usuario y el password seran entregados por el admin quien los ve desde la seccion patrullas desde la WAFA.
2. HOME: En esta pagina se vera el torneo en curso, la cantidad de blancos ordenados como corresponda (si a esa patrulla le toca iniciar desde el blanco numero 5, aparecera primero el 5, luego el 6, ...., por ultimo el 4).
Cada blanco debe mostrar el numero, la modalidad y la cantidad de flechas. Para anotar el puntaje es necesario darle click al blanco.
3. PAGINA_BLANCOS: En esta pagina se muestra nuevamente, la modalidad, la cantidad de flechas, la descripcion, los arqueros de la patrulla, la posicion en la cual tira cada uno y la estaca. Cuando se cargan los puntajes se deben mostrar ordenados de mayor a menor. Una vez se cargan los puntajes de todos los arqueros se da click al boton continuar y se pasa al siguiente.
4. PAGINA_RESULTADOS: En esta pagina se ven las estadisticas de cada arquero (puntage, cantidad de X, 10 y M). Se puede ir haciendo seguimiento durante el torneo.

Una vez se terminan de anotar los puntajes de todos los blancos se habilitar el boton de "Resultados". Al darle click se muestra en una nueva pagina los resultados de cada arquero (puntaje en cada blanco, puntaje total, cantidad de X, 10 y M). De bajo de las estadisticas de cada usuario hay un boton de FIRMAR (esto permite firmar desde la pantalla del celu).

Una vez que todos los arqueros firmen sus puntajes, se habilita el boton de "Finalizar". Con la accion de este boton se finaliza el torneo y ya no se puede editar.
