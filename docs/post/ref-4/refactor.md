# Cuarto refactor — pedido del cliente

Registro literal del pedido, para que el plan pueda referenciarlo.

1. En la página de acceso a la WAFA y WAFL agregar botón para ir a la Landing y recomendar al usuario si quiere instalar la app en su mobile (modal con accionable).
2. Avisar a los usuarios cuando hay una nueva versión de la aplicación con un accionable para instalarla.
3. Acomodar página de pagos, UI se rompe. Está toda la info en una sola línea, colocar el nombre y estado en la primera fila y los accionables en la segunda.
4. Acomodar página de torneos (Landing), UI se rompe. Colocar nombre y categoría en la primera fila y estaca en la segunda.
5. Renombrar categorías para ganar espacio con un diccionario:
   - Categorías: recurvo olímpico → recurvo, compuesto libre → compuesto, compuesto cazador → cazador, razo → razo, tradicional → tradicional, longbow → longbow
   - Modalidades: Sala 18m → 18m, aire libre → aire libre, juego de campo → campo, 3d → 3d
6. Acomodar logos en header en una sola línea. Colocar el logo del CBA a la izquierda, luego al lado el de la liga y del lado derecho «Liga Bahiense».
7. La sección de firma se puede mejorar. El lugar donde se presiona y se dibuja difieren, es necesario que donde se haga click se inicie a dibujar.
